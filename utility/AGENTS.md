## What this category is

Each skill here is invoked on its own and shares no artifact chain:

- `init-agents-md` — generates a minimal `AGENTS.md` for the current repository.
- `solo-review` — reviews code changes against loose context.
- `solo-address-review` — validates review findings and fixes confirmed issues without pipeline documents.
- `push-review` — posts a local review file to a GitHub pull request as inline review comments.
- `pull-review` — writes all review activity of a GitHub pull request to `REVIEW.md`.
- `commit` — commits staged or specified files with a Conventional Commits message after approval.
